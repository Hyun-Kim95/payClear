# design-brief — AI 티 / 금지 패턴

목업·구현 리뷰에서 **이름이 붙은 패턴**으로 탈락시킨다.  
“별로다”가 아니라 “금지 #N 위반”으로 말한다.

## 공통 금지

| ID | 금지 | 허용 예외 |
|----|------|-----------|
| AP-01 | 가운데 정렬 히어로를 **기본값**으로 사용 | 브랜드가 의도적으로 센터 심볼일 때 + 브리프에 사유 |
| AP-02 | 동일 카드 3장을 가로로 나열(아이콘+제목+짧은 문장) | 대시보드에서 **상호작용 단위** 카드이고 내용이 서로 다를 때 |
| AP-03 | 이미지+텍스트 좌우 교차(zigzag) **3회 연속** | 최대 2회, 3번째부터 다른 레이아웃 |
| AP-04 | 대문자 라벨(eyebrow) — **세 섹션당 1개** 초과 | — |
| AP-05 | 마키/흐르는 텍스트 — **페이지당 1개** 초과 | — |
| AP-06 | 보라 네온 글로우, 퍼플→인디고 기본 그라데이션 테마 | 브랜드 가이드에 보라가 **명시**된 경우만 |
| AP-07 | 근거 없는 수치(92%, 4.1×, “사랑받음”) | 출처·측정 정의가 브리프/PRD에 있을 때만 |
| AP-08 | 가짜 인명·회사(John Doe, Acme Corp 남발) | 명시적 placeholder 정책 + `예:` 표기 |
| AP-09 | Inter / Roboto / Arial / system-ui만으로 디스플레이 구성 | 제품 UI(`product`/`dashboard`)에서 기존 토큰 폰트 유지 |
| AP-10 | 웜 크림 배경 + 고대비 세리프 + 테라코타 액센트 클리셰 | 브랜드 가이드 명시 시 |
| AP-11 | 히어로 위 플로팅 배지·프로모 칩·탈착 라벨 오버레이 | — |
| AP-12 | 히어로를 inset 카드·사이드 패널·타일 콜라주로 축소(랜딩/프로모) | 기존 DS가 요구할 때 |
| AP-13 | 장식용 추상 그라데이션만으로 “비주얼 앵커”를 대체 | 제품·장소·분위기 실사/구체 이미지 또는 동등 앵커 |
| AP-14 | 첫 뷰포트에 통계·스케줄·주소·프로모·메타데이터 동시 배치 | `dashboard`는 밀도 축에 따름 |

## surface 힌트

- **landing / portfolio / marketing:** AP-01~14를 엄격 적용. 시그니처 없으면 미완성.
- **product:** AP-02·AP-09는 DS 존중. 분산·모션은 낮게. 상태 UI 누락이 더 큰 결함.
- **dashboard:** 밀도 높음 허용. “카드 금지”는 **장식 카드**에만 적용. 상호작용 컨테이너는 허용.
